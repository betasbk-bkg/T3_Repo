# Repository Manifest

This archive supports the manuscript **Local relief without global closure: hybrid obstruction channels in delayed quantized collective control**.

Version: v1.6.1

Author: Bongkeun Song

Affiliation: Friedrich-Alexander-Universität Erlangen-Nürnberg (FAU), Germany

## Top-Level Layout

- `README.md`: package overview and reproducibility boundary.
- `CITATION.cff`: citation metadata for the archive.
- `LICENSE`: MIT license for `code/`.
- `LICENSE-DATA.md`: CC BY 4.0 license for `data/`, `figures/`, and `supplements/`.
- `supplements/`: Supplementary Information S1-S3.
- `figures/`: manuscript figures and high-resolution figure files.
- `data/`: processed data and table-supporting files used by the manuscript.
- `code/`: package-relative analysis scripts and copied fixed-engine source.
- `metadata/`: DOI audit, figure mapping, release notes, availability statement, and file checksums.

## Checksums

File-level SHA256 checksums are listed in `metadata/repository_file_manifest_sha256.csv`. The checksum table excludes itself to avoid a circular checksum.
