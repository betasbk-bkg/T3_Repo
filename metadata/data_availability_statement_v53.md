# Data Availability Statement

The code, simulation configurations, processed data, analysis scripts, final figure image files, table-supporting materials, and supplementary information source files for this study are included in this repository archive.

This archive is deposited on Zenodo. The concept DOI 10.5281/zenodo.20704461 resolves to the latest archived version; the version-specific DOI for this release is recorded in the Zenodo record and cited in the manuscript's Data availability statement.
