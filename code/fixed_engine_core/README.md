# Fixed Engine Core

This directory contains copied source files from the fixed T3 engine archive for implementation-lineage and q=8 reproducibility context.

## Scope

- The engine core preserves the fixed q=8 implementation used by the original 96-cell grid.
- The q=4/q=8/q=16 structural audit is produced by the package-relative scripts in `code/analysis/`.
- The manuscript-supporting evidence is stored outside this directory under `data/`, `code/analysis/`, `figures/`, `supplements/`, and `metadata/`.

This directory is not the repository root README.
